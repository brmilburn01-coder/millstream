# Millstream · Bible Reading Plan

> *Read it. Understand it. Live it.*

A full-year Bible reading plan with Sunday Psalms, deep study overviews, and Head / Heart / Hands notes — built as a Progressive Web App so it installs on your iPhone or iPad like a native app.

## Features

- 52 weeks of structured readings (Sunday Psalms + Mon–Sat chronological)
- Weekly overview teaching with Big Picture, Christ Connection, and application
- Deep Study layer: historical context, hermeneutics, key words, theology threads
- Head / Heart / Hands notes saved persistently to your device (IndexedDB)
- KJV text embedded natively — works fully offline
- ESV text via free API key (get one at api.esv.org) 
- CSB via Bible Gateway link
- Progress tracking with export/import backup
- Installs as a PWA on iPhone/iPad — add to home screen from Safari

## How to Use

1. Open the link in Safari on your iPhone or iPad
2. Tap the Share button → "Add to Home Screen"
3. Millstream will install like an app with its own icon
4. Your notes and progress are saved to your device

## ESV Setup (Optional)

1. Go to [api.esv.org](https://api.esv.org) and create a free account
2. Click "Create an API Application"
3. Paste your key into Millstream when prompted
